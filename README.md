# mykahawa.org

MyKahawa is a market intelligence platform for Kenyan coffee: Nairobi Coffee Exchange auction prices, grades and buyers, and a directory of growers, exporters, dealers and millers.

The site is built with Jekyll and hosted on GitHub Pages (branch `gh-pages`).

## Structure

- `index.html` – homepage; `transactions.md` – prices and charts; `directory.md`, `dealers.md`, `list/producers.html` (growers map and search)
- `directory/` – directory category pages; `directory/county/` is generated by the data script
- `_layouts/directory.html` – layout that renders directory tables from `_data`
- `_projects/` – Kenya coffee guides (grades, laws, glossary…); `_producers/` – grower profiles; `_node/` – static pages
- `_data/` – data read at build time (`navigation.yml`, plus JSON generated by the data script)
- `theme/js/` – map, search and chart scripts; `theme/vendor/` – self-hosted libraries (Leaflet, Chart.js, jQuery, Bootstrap JS)
- `theme/_sass/_mk.scss` – site styles

## Updating data

Raw datasets in `data/` are **not published** on the website (see `exclude` in `_config.yml`). After changing them, regenerate the derived files:

```
python3 scripts/build_data.py
```

This rewrites `_data/*.json`, `data/growers/growers.json`, `data/growers/growers_map.geojson`, `data/market/*.json` and the county pages.

## Local preview

```
bundle install
bundle exec jekyll serve
```

Or with Docker (no local Ruby needed):

```
docker run --rm -p 4000:4000 -v "$PWD":/site -w /site ruby:3.3 \
  bash -c "bundle install && bundle exec jekyll serve --host 0.0.0.0"
```
